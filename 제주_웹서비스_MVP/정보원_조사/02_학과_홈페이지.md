# 02. 학과·단과대 홈페이지 공지 게시판

- 조사일: 2026-11-21(토) 밤, 웹 Claude Code 에서.
- 로컬에서 돌던 02 조사는 끝나지 않아서 웹에서 새로 썼다.
- 표기
  - **[확인]** = 01·05 조사 때 curl 로 직접 열어 본 것
  - **[검색]** = 이번에 검색엔진 색인(캐시)으로 본 것. 실제 페이지가 아니라 검색엔진이 언젠가 긁어 간 사본이라 날짜가 제각각이다
  - **[추측]** = 근거가 약한 짐작
- 한계부터 적는다. 이번 세션은 네트워크 정책 때문에 `*.jejunu.ac.kr` 에 아예 접속하지 못했다(프록시가 CONNECT 403, WebFetch 는 DNS 실패). 그래서 학과 게시판을 직접 열어 본 것은 05 의 약학대학 한 곳뿐이고, 나머지는 검색 결과로 주소와 글 종류만 모았다.
- 학과 사무실 전화번호, 글쓴이 이름은 적지 않았다.

## 1. 결론

학과 사이트도 본부와 같은 artpq CMS 위에 있다. 근거는 셋이다.

1. 글 주소가 모두 `<게시판>.htm?act=view&seq=<번호>` 꼴이다 [검색].
2. seq 번호가 본부와 같은 범위에 있다. 약학대학 글이 seq 255642·261537·263052·269190, 수의학과가 268738, 전자공학과가 260133 이다 [검색]. 05 에서 본 최근 전역 seq 는 약 283,5xx 였다 [확인]. 학과 글도 전역 번호를 같이 쓰는 것으로 보인다 [추측, 근거는 번호 범위].
3. `cms.jejunu.ac.kr/prevetmedmain/community/notice.htm` 처럼 **cms 호스트 뒤에 사이트 경로만 붙여도 학과 게시판이 열린다** [검색]. 서브도메인은 겉 이름일 뿐이고 실제로는 한 서버가 첫 경로(`/pharmacy/`, `/prevetmedmain/`)로 사이트를 나눈다는 뜻이다.

그래서 01 의 `artpq_table` 파서를 그대로 쓸 수 있을 가능성이 크다. 다만 게시판 경로는 학과마다 달라서, 주소 목록은 한 번 사람이 만들어야 한다.

## 2. 게시판 주소 꼴

세 가지가 보였다.

| 꼴 | 보기 | 학과 |
|---|---|---|
| A. `/<사이트>/index/community/notice.htm` | `https://admini.jejunu.ac.kr/admini/index/community/notice.htm` | 행정학과, 경제학과(econ), 관광개발학과(td), 관광경영학과(tourism), 음악학부(music), 생물학과(lifescience), 멀티미디어디자인전공(multi), 해양시스템공학과(ose → 경로는 `/osejeju/`), 데이터사이언스학과(jupiter → 경로는 `/computer/`) [검색] |
| B. `/<사이트>/community/notice.htm` | `https://pharmacy.jejunu.ac.kr/pharmacy/community/notice.htm` | 약학대학 [확인], 전자공학과(comdol), 메카트로닉스공학전공(mechatronic), 독일학과(ifdk) [검색] |
| C. 그 밖 | `https://nursing.jejunu.ac.kr/nursing/degree/notice.htm` | 간호학과(학부 공지는 `degree/notice.htm`, 대학원 공지는 `graduateschool/notice.htm`, 보도자료 `community/news.htm`), 수의학과(`/vetmedmain/community/notice.htm`), 수의예과(`/prevetmedmain/community/notice.htm`) [검색] |

눈여겨볼 점:
- 서브도메인과 경로 이름이 다른 곳이 있다(jupiter → `/computer/`, ose → `/osejeju/`, vetmed → `/vetmedmain/`). 서브도메인만 보고 주소를 만들면 틀린다.
- 수의학과와 수의예과는 사이트가 따로다. 간호학과는 학부·대학원 공지가 나뉜다. "학과 하나 = 게시판 하나"가 아니다.
- 지구해양과학과는 `earthocean.jejunu.ac.kr/earth/index/degree/scholarship.htm` 에 장학 안내 쪽이 따로 있다 [검색]. 공지 게시판과 별개인지는 모른다.
- 검색 색인에 `?_layout=playout&_view=print` 가 붙은 인쇄용 주소가 많이 잡혀 있다 [검색]. 01 에서 `_layout=none` 은 오류였다 [확인]. 인쇄용 화면은 메뉴가 빠진 가벼운 HTML 일 수 있다 [추측]. 열어 볼 수 있게 되면 시험해 볼 것.

## 6. 학과 게시판 목록 만드는 법 (제안)

1. 본부 `https://www.jejunu.ac.kr/colleges.htm`(대학/학부 목록) [검색, 주소만 봄] 에서 학과 사이트 링크를 모두 뽑는다. 05 에서 서브도메인 약 200개를 찾을 때 쓴 방식과 같다.
2. 학과 사이트마다 첫 화면을 받아, 글자가 "공지" 인 메뉴 링크를 찾는다. 못 찾으면 2절의 A·B 꼴을 차례로 넣어 본다.
3. 그 결과를 `sources/departments.yaml` 로 저장하고 사람이 한 번 훑어본다(학과 이름, 게시판 주소, 마지막 글 날짜). 6개월 넘게 글이 없는 게시판은 빼 둔다.
4. 학과 개편으로 주소가 바뀔 수 있으니 이 목록 만들기는 학기마다 한 번 다시 돌린다.

학과 수는 확인하지 못했다. 05 의 단과대·학과 서브도메인과 이번 검색에서 본 학과만 세어도 40곳이 넘는다. 게시판 하나에 요청 한 번, 사이에 3초를 쉬면 한 바퀴에 3~4분쯤 걸린다 [추측].

## 7. 파서 메모

- 01 의 셀렉터(`table tbody tr`, `td.title a@title`, `td.nowrap` 날짜, `tr.info` 고정 공지)를 먼저 그대로 써 본다. 05 에서 hpc·gs 는 날짜가 `YYYY.MM.DD` 였다 [확인]. 날짜는 두 꼴을 다 받게 한다.
- 학과 사이트는 작성자 칸에 학과 이름이 들어간다(수의학과 사본에 "수의학과") [검색]. 사람 이름이 들어가는 학과가 있으면 저장하지 않는다.
- 중복: seq 가 같으면 하나로 합친다. 학과가 본부 글을 새로 올렸다면 seq 가 다를 수 있으니, 제목을 정규화(공백·괄호·[ ] 머리말 제거)한 값이 같고 날짜가 3일 안이면 합친다.
- 학과 게시판은 글이 적으니 `pageSize` 를 키울 필요가 없다. 첫 페이지면 된다.
