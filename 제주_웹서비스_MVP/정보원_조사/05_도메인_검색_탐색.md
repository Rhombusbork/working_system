# 05. 도메인·검색 탐색 — 메뉴 밖에 숨은 정보원 찾기

조사일: 2026-11-21 (KST) · 조사 방식: 인증서 투명성 로그(crt.sh) + 허브 페이지 링크 추출 + DNS 추측 + 실제 HTTP 응답 확인 + 웹검색

> **표기**: ✅ = 실제로 요청해서 확인함 / 🔸 = 추측(확인 안 함 또는 간접 근거)

## 1. 요약 (먼저 읽을 것)

1. **서브도메인 약 200개를 찾았다.** crt.sh 에서 126개(인증서 기록), 허브 페이지(www·cms·clip·jnurise·esac) 링크에서 72개 더, DNS 추측으로 몇 개 더(`jnurise`, `changup`, `jedaero` 등). ✅
   - crt.sh 만으로는 부족했다: `jedaero`(산학 프로그램 플랫폼), `jnurise`(RISE 포털), `glocal`, `support`, `hpc` 같은 핵심 사이트가 crt.sh 에 없었다. ✅
2. **학교 사이트 대부분이 같은 CMS 하나로 돌아간다.** IP `192.203.138.15`(www, cms, clip, counsel 등 공유). 게시판 주소 꼴이
   `https://<사이트>.jejunu.ac.kr/<사이트>/…/notice.htm`, 목록 `?page=N`, 본문 `?act=view&seq=N` 로 모두 같다. ✅
   → **수집기(파서) 하나를 만들면 수십 개 센터·학과 공지를 같이 읽을 수 있다.** 목록은 서버가 그린 HTML 표 (번호·제목(title 속성에 전체 제목)·첨부·작성자·작성일·조회). ✅
3. **`seq` 는 사이트 전체가 함께 쓰는 번호다.** clip 사이트 주소로 생활관 글(seq=283503)을 열어도 그 글이 보였다. ✅
   즉 글 번호가 모든 CMS 사이트에서 하나로 늘어난다 (최근 약 283,5xx). 새 글 감지에 쓸 수는 있으나 어느 게시판 글인지 안 나오므로 MVP 에서는 **게시판 목록 크롤링**이 맞다.
4. **robots.txt 주의**: `www`, `clip`, `dormitory` 등 CMS 사이트는 `User-agent: * / Disallow: /` (전체 차단). `jnurise` 는 `Allow: /`, `news` 는 `/admin/` 만 막음. ✅
   → 과제 MVP 라도 **요청 간격을 길게(예: 게시판당 하루 몇 번), 목록 첫 페이지만** 읽고, 출처 링크를 반드시 달자. 정식 서비스로 키우려면 학교 허락이 필요하다.
5. **가장 쓸모 있는 새 정보원 두 곳**:
   - **제대로 산학1번지 `jedaero.jejunu.ac.kr`** — RISE·LINC·창업지원단·산학협력단 등 30여 부서의 **프로그램 목록이 로그인 없이** 유형·담당부서·접수 시작/종료일·접수중/예정/마감·D-DAY 까지 표로 나온다 (총 85건). ✅ 구조화 품질 최고.
   - **제주대미디어 RSS `news.jejunu.ac.kr/rss/allArticle.xml`** — 학내 신문 전체 기사 RSS, 2026-11-19 기사까지 최신. ✅
6. **비교과 프로그램 신청·마일리지·이수 확인은 모두 포털(portal.jejunu.ac.kr) 안, 로그인 필수.** 공개 목록 없음. ✅ (교수학습지원센터 'JNU-CHANGE 비교과' 안내 문구로 확인)
   대신 각 센터 공지 게시판과 jedaero 에 신청 안내가 공개로 올라온다 → 이걸 모으는 게 현실적이다.
7. 웹검색은 거의 도움이 안 됐다 (RISE·LINC·SW중심대학·비교과 검색 모두 다른 대학이나 뉴스만 나옴). 직접 탐색이 훨씬 낫다. ✅

## 5. 수집기 만들 때 메모 (기술)

- **CMS 목록 파싱** (✅ clip 으로 확인): `<td class="title" … title="전체 제목"><a href="…?act=view&amp;seq=N">`, 작성일 `<td class="nowrap">YYYY-MM-DD</td>`, 작성자 칸, 첨부는 `act=download&seq=N&no=K`. 페이지 수 `총 <strong>N</strong>페이지`. 사이트마다 날짜가 `YYYY.MM.DD` 인 곳도 있음(hpc, gs).
- 검색 파라미터: `q`, `qType`(title/contents/writer/titlecontents) — 장학·모집 같은 키워드 필터를 서버에서 바로 쓸 수 있음 🔸(esac 의 ribs 링크에서 `?q=…&qType=title` 꼴 확인).
- RSS: CMS 게시판엔 없음(`?act=rss` 빈 응답 ✅). news 만 RSS 있음.
- TLS: www https 는 인증서 오류(-k 필요), linc·jedaero 는 DH 키 문제로 `SECLEVEL=0` 필요. Python 이면 `ssl` 컨텍스트에서 `set_ciphers('DEFAULT@SECLEVEL=0')`.
- 중복: changup = jnubi, 같은 글이 여러 센터에 재게시(clip 공지에 학생상담센터 글 등) → **seq 번호로 중복 제거**하면 됨 (seq 가 전역이라 가능 ✅).
- 부하: robots 차단 사이트가 많으므로 하루 1~2회, 첫 페이지만, User-Agent 에 서비스명·연락처를 밝힐 것.
