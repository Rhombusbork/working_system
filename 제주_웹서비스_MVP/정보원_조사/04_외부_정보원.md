# 04. 외부 정보원 (학교 밖) 조사

- 조사일: 2026-11-21
- 맡은 범위: 장학금, 청년 정책, 공모전·대외활동, 취업, 행사, 학생 커뮤니티 (제주대 본부·학과·학식은 다른 문서)
- 전제: 로그인·DB 없음. GitHub Actions 가 주기적으로 수집해서 정적 JSON 으로 만들고 GitHub Pages 로 보여 준다.
- 표기
  - **[확인]**: 이번에 curl 로 직접 열었거나 공식 페이지를 읽어서 확인함
  - **[추측]**: 검색 결과나 일반 지식으로 짐작함. 실제로 수집하기 전에 다시 확인해야 함
  - 접근: curl 에 일반 브라우저 UA 를 넣어 HTTP 200 과 본문이 오는지 봄 (GitHub Actions 는 해외 IP 라서 결과가 다를 수 있음. 특히 `.go.kr` 사이트)
  - 질: 제주대 학생에게 얼마나 쓸모 있는지 (상/중/하)
  - API 키: 공공데이터포털(data.go.kr) 키는 회원가입하고 활용신청해야 받을 수 있음. 이번 조사에서는 가입하지 않았음

### 공통 수집 메모

- **키 관리**: data.go.kr 키 하나로 2·3·8·9번 (그리고 제주 행사축제·브리핑 API) 을 쓸 수 있다. GitHub Secrets 에 `DATA_GO_KR_KEY` 로 넣는다. 저장소가 공개되므로 키를 코드나 JSON 결과에 절대 쓰지 않는다.
- **해외 IP 문제**: GitHub Actions 는 미국 IP 다. 정부·공공 사이트(`.go.kr`, `.or.kr`)가 해외 접속을 막는 경우가 있다 [추측]. MVP 첫 주에 Actions 에서 한 번씩 시험해 보고, 막히는 곳은 ① data.go.kr API 로 바꾸거나 ② 집 PC 에서 cron 으로 돌려 push 한다.
- **robots 가 막는 곳** (제주도청 `/news/`, 서귀포시, 제주창조경제혁신센터, 제주테크노파크): 자동 수집하지 않고 **바로가기 링크**로만 둔다. 도청 소식은 data.go.kr 의 '제주브리핑'·'행사축제소식' API 로 대신 받는다.
- **저작권·예의**: 제목·날짜·원문 링크만 저장한다. 본문 전문이나 포스터 이미지는 다시 올리지 않는다. 요청 간격은 사이트마다 2~3초 이상, 하루 1~4회. User-Agent 에 서비스 이름과 연락처(저장소 URL)를 적는다.
- **중복**: 청년센터에는 콘텐츠진흥원·문화예술재단 글이 다시 올라온다. 제목을 정규화해서 비교하고 하나로 합친다.
- **갱신 주기 제안**: 청년센터·장학진흥원·공모전은 하루 2회, API 는 하루 1회, 장학 CSV 는 주 1회 (원본은 월간이지만 바뀐 날을 놓치지 않게).

### 확인 못 한 것 (다음에 할 일)

- data.go.kr 파일 CSV 를 로그인 없이 받을 수 있는지, 실제 다운로드 URL 형식
- 고용24·잡알리오 API 의 정확한 신청 방법과 승인 기간
- 위비티·씽굿·캠퍼스픽 이용약관에 자동 수집 금지 조항이 있는지
- 제주대 총학생회·단과대 인스타그램 계정명, 제주대 공식 블로그·유튜브 채널 ID
- 제주 일자리종합센터 공식 주소
- GitHub Actions(해외 IP)에서 위 사이트들이 열리는지
