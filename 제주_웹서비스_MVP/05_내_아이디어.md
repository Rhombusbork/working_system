# 내 아이디어 — 제주대 정보 모아 보기 (2026-11-21)

## 내가 말한 것

> 내가 다니는 제주대학교 관련 장학금, 행사 등의 정보를 모아 한번에 보여주는 웹사이트를 서비스하고 싶어.
> 특히 그 사람이 원하는 것이 정해져 있을 때 미리 말해 놓으면 그것과 관련된 것들만 계속 모으고 보여준다던지,
> 필요한 거 여러 사이트에 나누어져 있는 정보들을 한번에 모아 보여준다던지 하는 서비스.

## 핵심 기능 (후보)

1. **한곳에 모으기**: 여러 사이트(학교 공지, 학과 공지, 장학 공지, 행사 등)에 흩어진 글을 한 화면에.
2. **관심사 등록**: "장학금", "약학과", "공모전"처럼 미리 정해 두면 그것과 관련된 글만 계속 보여 준다.
3. (선택) 마감일이 있는 글은 마감 순으로.

## 과제 조건과 맞추기

| 조건 | 어떻게 |
|---|---|
| 제주 로컬 생활정보 | 제주대 학생의 생활정보 |
| 로그인·결제·DB 없음 | 관심사는 브라우저에 저장. 글 모으기는 GitHub Actions 가 정해진 시간마다 긁어 JSON 파일로 저장 → GitHub Pages 에서 보여 줌 |
| 사용자 5명 이상 테스트 | 제주대 학생(약학과·HRA 동기) |
