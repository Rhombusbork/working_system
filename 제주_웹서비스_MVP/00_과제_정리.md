# 12/12 기업실무 기획과제 — 바이브코딩을 활용한 제주 로컬 웹서비스 MVP 제작 (1조, 내 발표)

출처: 과제 안내 캡처 `KakaoTalk_20261120_135555760.png` (2026-11-20). 같은 주 경영서는 『무기가 되는 스토리』(도널드 밀러).

## 개요

제주 지역의 관광, 로컬 상품, 음식, 체험, 이동, 생활정보 등과 관련된 **고객 불편을 하나** 고른다. 이를 해결하는 간단한 웹서비스 MVP를 바이브코딩으로 만든다.

## 학습 목표

- 고객 문제를 정의하는 방법을 익힌다.
- 서비스 콘셉트와 핵심 기능을 설계한다.
- 바이브코딩으로 간단한 웹서비스를 제작한다.
- 사용자 피드백을 정량화한다.

## 할 일 (순서대로)

- [ ] 제주 관련 고객 문제 하나 선정
- [ ] 타깃 사용자 정의
- [ ] 서비스명과 핵심 가치
- [ ] 핵심 기능 2~3개
- [ ] 사용자 입력 항목 설계
- [ ] 결과 화면 구성 설계
- [ ] 피드백 수집 항목 설계
- [ ] 바이브코딩으로 제작
- [ ] 잠재 사용자 5명 이상 테스트
- [ ] 피드백으로 개선 방향 정리

## 평가지표

문제 정의의 명확성 · MVP 기능의 적절성 · 사용 편의성 · 문제 해결 만족도 · 재사용 의향. **사용자 5명 이상 피드백 포함 필수.**

## 산출물

서비스 기획서 · 웹서비스 MVP 링크 또는 화면 캡처 · 사용자 피드백 분석표 · 개선 제안

## 주의 사항

- 로그인, 결제, 데이터베이스 연동은 요구하지 않는다.
- 완성도 높은 개발보다 고객 문제를 해결하는 최소 기능에 집중한다.
